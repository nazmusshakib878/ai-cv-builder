## ✨ Overview

**AI CV Builder** is a conversational AI-powered resume creation platform designed for users of all technical skill levels.

Instead of filling out complicated forms, users can simply talk to the AI naturally.

For example:

> **"আমার CV টা professional করে দাও"**

> **"Experience ta aro strong kore likho"**

> **"Make my CV ATS friendly"**

> **"CV ta one page e niye aso"**

The AI understands the instruction, updates the resume, and instantly reflects the changes in the live CV preview.

The goal is simple:

> **You don't need to understand CV building. Just tell the AI what you want.**

# ⚙️ Local Development

## 1. Clone the Repository

```bash
git clone https://github.com/nazmusshakib878/ai-cv-builder.git
cd ai-cv-builder
```

## 2. Install Dependencies

```bash
npm install
```

## 3. Configure Environment Variables

Create:

```text
.env.local
```

Add:

```env
NEXT_PUBLIC_BASE_URL=http://localhost:3000

OPENAI_API_KEY=

JWT_SECRET=

NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=

BKASH_APP_KEY=
BKASH_APP_SECRET=
BKASH_USERNAME=
BKASH_PASSWORD=
BKASH_BASE_URL=
```

> Never commit `.env.local` or production secrets to Git.
